# Mentalytics AI

Mentalytics AI is an AI-powered platform that analyzes adolescent mental health and social media usage data through an interactive chat interface. Users can ask natural language questions and receive data-driven insights based on a pre-integrated dataset.

The system helps bridge the gap between complex data analysis and non-technical users by providing simple, conversational access to insights about behavior patterns such as social media usage, sleep quality, stress levels, anxiety, and academic performance.

---

## Features

- Natural language chat interface for data exploration  
- AI-powered data analysis and insight generation  
- Correlation analysis between behavioral and mental health variables  
- Pre-integrated dataset (no file upload required)  
- Simple and intuitive user experience  

---

## Tech Stack

Frontend: Next.js  
AI Workflow & Agent: Langflow  
LLM Integration: AI Agent via Langflow pipeline  
Styling: Tailwind CSS (if used)  

---

## How It Works

1. User sends a question via chat input
2. Next.js sends the request to the backend workflow
3. Langflow AI Agent processes the query using the dataset
4. System analyzes patterns, correlations, and insights
5. Result is returned as a natural language response in chat output  

---

## Example Queries

1. Does TikTok usage affect anxiety levels?
2. What is the relationship between sleep and academic performance?
3. Which factor contributes most to stress in teenagers?  

---

## Goal

To make mental health and behavioral data analysis more accessible, understandable, and interactive through AI-powered conversation.
